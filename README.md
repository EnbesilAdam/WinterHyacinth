## 🚀 Active Projects & Focus Areas

* **🎮 Game Development:** Designing immersive visual novel experiences using the Ren'Py engine and crafting classic 2D game projects within GameMaker.
* **⚙️ System Tools & Automation:** Building centralized orchestrator systems (like Cardinal AI) using C# to manage and automate multi-tier applications and workflows.
* **🌐 Web & Backend Systems:** Developing scalable three-tier management systems involving Android applications, C# management interfaces, and robust MySQL databases.
* **🖥️ Infrastructure & Hosting:** Deploying and managing dedicated Linux environments (Ubuntu VPS) to host optimized game servers, automation tasks, and custom backend utilities.
